## 🛠️ 2. Yapılan Değişiklikler

### A. Yeni: `src/hooks/useOemShieldStatus.ts`

`detectOEMShieldStatus()` etrafında modül seviyesinde tek paylaşımlı state:

- **Tek okuma:** `inFlight` promise dedup + `OEM_SHIELD_REFRESH_THROTTLE_MS = 1500` throttle. İki ekran aynı tick'te mount olursa ikinci çağrı birincinin promise'ini bekler.
- **Otomatik yenileme:** `AppState 'active'` → throttle'lı yenileme. `notifySettingsOpened()` çağrıldıysa dönüşteki ilk `active`'de throttle atlanır + `SETTINGS_RETURN_SETTLE_MS = 700` bekleme.
- **Faz ayrımı:** `unknown` → `loading` → `resolved` + ayrı `isRefreshing`. UI uyarıları yalnızca türetilmiş `isResolved` true iken gösterilir.
- Hata durumunda eski veri korunur; hiç veri yoksa faz `unknown` kalır → uyarı gösterilmez.
- `AppState` erişilemezse (kısıtlı ortam / eksik test mock'u) hook sessizce otomatik yenilemeden vazgeçer, **ekranı çökertmez**.

### B. `AlarmDiagnosticCard.tsx`
- `isBatteryIgnored` / `canUseFSI` / `isXiaomi` / `isRefreshing` lokal state'leri ve `checkSystemHealth()` + mount `useEffect`'i kaldırıldı.
- `notifee` importu düştü (artık `isBatteryOptimizationEnabled` çağrılmıyor).
- **Kesin alarm rozeti gerçek değere bağlandı** (`status.exactAlarm`): üç durumlu — Kontrol ediliyor (nötr) / USE_EXACT_ALARM: Aktif (yeşil) / Kesin Alarm İzni: Kapalı (amber).
- Pil rozeti de üç durumlu hale getirildi.
- Yenile butonu `refresh()` (force), `handleOpenLockScreenPermission` önce `notifySettingsOpened()` çağırıyor.
- Yan düzeltme: eksik `Medicine` / `ReminderTime` tip importu eklendi (4 adet TS2304 giderildi).

### C. `NotificationsSection.tsx`
- Aynı hook'tan okuyor. `isResolved && status.fullScreenIntent === false` iken **toggle'ın hemen altında** amber uyarı satırı.

### D. Testler
- `AlarmDiagnosticCard.test.tsx`: rozet artık hardcoded olmadığı için hook mock'landı; `AppState` + `NativeModules` mock'a eklendi. **2 yeni test**: (1) veri hazır olmadan nötr "Kontrol ediliyor…" ve **uyarı flash etmemesi**, (2) izin geri alındığında rozet + kilit ekranı satırının doğru görünmesi.
- `SettingsScreen.test.tsx`: `AppState` mock'u eklendi.

## 📌 4. Bu Adımdan Çıkan, Henüz Kapatılmayan Eksikler

1. **Xiaomi'de kilit ekranı satırı koşulsuz görünüyor.** Kart koşulu `oem === 'xiaomi' || fullScreenIntent === false`. MIUI'nin "arka planda açılır pencere" izni Android API'siyle sorgulanamadığı için izin verilmiş olsa da satır kalıyor.
2. **`rollingHorizonScheduler.ts` gerçek `Medicine` tipiyle uyuşmuyor** — `durationDays`, `times` okuyor, `frequency`'yi string ile karşılaştırıyor (kalan 26 tsc hatasının 7'si). "14 Günlük Planlanan Doz" sayısının doğruluğu buna bağlı.
3. **`TimelineItem` / `CurrentDoseCard` testleri saat bağımlı (flaky)** — `time: '23:59'` sabitini gerçek duvar saatine karşı kullanıyor, `useFakeTimers` yok.
