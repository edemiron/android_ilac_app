## 0. Beklenmeyen bulgu: depoda İKİ Expo yapılandırması vardı ve yanlış olan kazanıyordu

Boyut işine başlamak için `app.json`'daki plugin listesini temizlemeye
gittiğimde depoda ikinci bir dosya olduğunu gördüm: **`app.config.json`**.

Expo'nun çözümleme sırası `app.config.*` dosyasını `app.json`'ın **ÖNÜNE**
koyar. Yani gerçek yapılandırma aylardır `app.json` değil, `app.config.json`
idi. Kanıt:

```
$ npx expo config --type public --json     # (v1.8.0, düzeltmeden önce)
version           1.6.0        ← app.json 1.8.0 diyordu
versionCode       37           ← app.json 59 diyordu
functionsBaseUrl  "REPLACE_WITH_ENV_FUNCTIONS_BASE_URL"
privacyPolicyUrl  "REPLACE_WITH_ENV_PRIVACY_POLICY_URL"
plugins           expo-camera, react-native-vision-camera, expo-font,
                  @react-native-google-signin/google-signin,
                  @react-native-firebase/app-check, ...
```

`scripts/sync-version.js` bu dosyayı hiç bilmiyordu. Yani **her sürüm
yükseltmesi sessizce yarım kalıyordu**: `version.ts`, `app.json`,
`package.json` ve `build.gradle` senkronize oluyor, Expo'nun okuduğu
yapılandırma 1.6.0 / 37'de donuyordu.

### Neden şimdiye kadar patlamadı

Şans eseri. Bu proje `android/` klasörünü depoda tutuyor ve
`npm run build:release` yalnızca `react-native bundle` + `gradlew
assembleRelease` çalıştırıyor — **`expo prebuild` hiç çalışmıyor**. Bu yüzden
`app.config.json`'daki plugin listesi, izinler ve intent-filter'lar native
derlemeyi etkilemiyordu; `AndroidManifest.xml` elle yönetiliyor ve gerçek
kaynak o. Sürüm numarası da `build.gradle`'dan geliyor, uygulama içinde
gösterilen sürüm ise `Constants.nativeAppVersion` (BuildConfig) üzerinden
okunuyor.

Canlı etkisi olan tek tüketici `src/config/firebase.ts` →
`Constants.expoConfig.extra.firebase`. Bu blok iki dosyada **aynı** değerleri
taşıdığı için Firebase bağlantısı bozulmadı. Yani bomba patlamadı ama
kurulmuştu:

- `app.config.json`, kurulu **olmayan** paketleri plugin olarak listeliyordu
  (`@react-native-firebase/app-check`, ve bu sürümde kaldırdığım
  `expo-camera` / `expo-localization`). `expo-constants` derleme sırasında
  `expo config` çalıştırır; listedeki bir plugin çözülemezse komut **hata
  verir** ve build kırılır. Yani "bir gün paket kaldıran" kişi, sebebi
  görünmeyen bir derleme hatasına çarpacaktı.
- `functionsBaseUrl` / `privacyPolicyUrl` doldurulmamış placeholder'lar
  olarak yapılandırmada duruyordu.
- Bir gün `expo prebuild` çalıştıran kişi `AndroidManifest.xml`'i 1.6.0
  döneminin izin listesiyle (`SYSTEM_ALERT_WINDOW`,
  `FOREGROUND_SERVICE_SPECIAL_USE`) ve **`USE_EXACT_ALARM` OLMADAN** yeniden
  üretecekti.

### Aynı sınıf hata bu projede ikinci kez

Arşivde `v1.7.1` kaydı şunu söylüyor: *"build.gradle bu script'in kapsamında
DEĞİLDİ; sonuç olarak store'a giden sürüm ile uygulama içinde gösterilen

genişletilmişti; bu sefer **kapsanacak ikinci dosyayı yok ettim**, çünkü

## 2. Kaldırılanlar ve neden ölü olduklarının kanıtı

### 2.1 ML Kit barkod modeli gömülüydü — 8.64 MB

`libbarhopper_v3.so` (7.81 MB, iki ABI) + `assets/mlkit_barcode_models/*.tflite`
(0.83 MB) `react-native-vision-camera`'nın kod tarayıcısından geliyordu.
Kütüphanenin kendi `build.gradle`'ı iki yol sunuyor
(`node_modules/react-native-vision-camera/android/build.gradle:202-209`):

```gradle
if (enableCodeScanner) {
  // User enabled code-scanner, so we bundle the 2.4 MB model in the app.
  implementation 'com.google.mlkit:barcode-scanning:17.3.0'
} else {
  // ... On devices with Google Play Services, this can also download
  // the CodeScanner model on-demand.
  implementation "com.google.android.gms:play-services-mlkit-barcode-scanning:18.3.1"
}
```

`VisionCamera_enableCodeScanner=true` → `false`. **Özellik kalkmıyor**:
CodeScanner kodu yine derleniyor, model ilk kullanımda Play Services'ten
iniyor. Bayrağın adı yanıltıcı; "tarayıcıyı kapat" değil "modeli göm"
anlamına geliyor.

**Kabul edilen taviz:** Play Services bulunmayan cihazlarda (Huawei vb.)
barkod tarama çalışmaz. Uygulama zaten Firebase / Google Sign-In / AdMob ile
GMS'e bağlı, yani yeni bir bağımlılık sınıfı eklenmiyor. Ayrıca barkod, ilaç
eklemenin zorunlu yolu değil — elle giriş ve e-reçete içe alma var.

### 2.2 BouncyCastle post-kuantum parametre tabloları — 3.94 MB

`org/` altındaki 4.05 MB'ın neredeyse tamamı **kullanılmayan post-kuantum
algoritmaların** parametre dosyalarıydı: `picnic/lowmc.properties` 1.50 MB,
`sike/p751.properties` 1.06 MB ve arkadaşları. `bcprov` transitif olarak
geliyor; ProGuard/R8 `.properties` **kaynak** dosyalarını (kod değil) hiçbir
zaman silmez. Bu yüzden paketleme seviyesinde dışarıya alındı:

```gradle
resources { excludes += ['org/bouncycastle/pqc/**',
                         'META-INF/*.version', 'DebugProbesKt.bin'] }
```

Sonuç: `org/` 4.05 → **0.11 MB**.

### 2.2b `kotlin/**` hariç tutulunca uygulama AÇILIŞTA ÇÖKTÜ — geri alındı

Aynı `excludes` listesine "Kotlin metadata'sı yalnızca `kotlin-reflect` için
gerekli, bu uygulamada refleksiyon yok" gerekçesiyle `kotlin/**` ve
`META-INF/*.kotlin_module` da eklemiştim. Testler yeşil, `tsc` temiz, build
başarılı — ve **cihazda uygulama beyaz ekranda kaldı**:

```
E/ReactNativeJS: Exception in HostObject::get for prop 'getRandomValues':
                 java.lang.AssertionError: Built-in class kotlin.Any is not found
  componentStack: at CaregiverEventBridge / AlertProvider / AuthProvider /
                  ... / ErrorBoundary / App
```

Gerekçe yanlıştı: **`expo-modules-core` modül kayıt defterini Kotlin
refleksiyonu ile kuruyor**, refleksiyon da `kotlin/kotlin.kotlin_builtins`
dosyasını okuyor. O dosya paketten çıkınca bütün Expo modül zinciri ölü
doğdu (`expo-crypto` → `react-native-get-random-values` → uuid → provider
ağacının tamamı). Kazancı da yalnızca **~0.01 MB**'tı.

İki satır geri alındı ve yerine `build.gradle` içine, aynı hatanın tekrar
denenmesini engelleyen bir uyarı bloğu yazıldı (hata metniyle birlikte, ki
arayan bulsun).

**Bu, bu sürümün en önemli dersi:** 194 suite / 2032 test, `tsc` ve `gradlew
assembleRelease`'in **hiçbiri** bu hatayı yakalamadı. Paketleme seviyesinde
kaynak silmenin tek doğrulaması cihazda açılıştır.

### 2.3 ~80 dilin string tablosu — 0.79 MB

AndroidX ve Play Services `resources.arsc`'ye onlarca dilin çevirisini
taşıyordu. Uygulama yalnızca TR ve EN konuşuyor (`LanguageContext`):

```gradle
androidResources { localeFilters += ['tr', 'en'] }
```

`resources.arsc` 1.35 → **0.56 MB**.

### 2.4 Kullanılmayan ikon fontları — 0.39 MB (ve bir gradle tuzağı)

`react-native-vector-icons` beş font gömüyordu; kodda **yalnızca iki tanesi**
import ediliyor (`Ionicons`, `MaterialCommunityIcons` — tüm `src/` taranarak
doğrulandı). `MaterialIcons.ttf`, `FontAwesome5_Solid.ttf`,
`FontAwesome6_Brands.ttf` hiçbir yerden çizilmiyordu.

Listeyi ikiye indirdim ve APK'yı yeniden ölçtüm: **beş font hâlâ içindeydi.**

### Yeni build script'leri

```json
"build:aab":       "npm run bundle && cd android && gradlew bundleRelease",
"build:apk:split": "npm run bundle && cd android && gradlew assembleRelease -Pandroid.enableAbiSplits=true"
```

ABI bölme **varsayılan olarak kapalı** (`android.enableAbiSplits=false`):
açıkken çıktı `app-release.apk` değil `app-<abi>-release.apk` olur ve
`build:device` script'i bunu bilmez. Elden APK dağıtımı için ayrı script var.

Bir de şu tuzağa düştüm: `gradlew assembleRelease bundleRelease
-Pandroid.enableAbiSplits=true` **kırılıyor** —

```
Execution failed for task ':app:buildReleasePreBundle'.
> Multiple shrunk-resources files found ...
  Please disable building multiple APKs when building an Android app bundle.
  (issuetracker.google.com/402800800)
```

AGP aynı çalıştırmada hem çok-APK hem AAB üretmiyor. Bayrağı açık bırakan
biri `npm run build:aab` çalıştırdığında sebebi anlaşılmaz bir hataya
çarpacağı için `splits.abi.enable` artık `bundle*` görevi istendiğinde
kendini kapatıyor (`isBundleTaskRequested`).

## 4. Yapılmayanlar ve nedenleri

- **`assets/index.android.bundle` 8.82 MB.** Artık en büyük tek giriş ve
  toplamın %15'i. Bir hatırlatma uygulaması için fazla; içinde ne olduğunu
  bulmak (source-map analizi) ayrı bir iş, tahminle kod silmek istemiyorum.
  **Sıradaki en büyük kazanç burada.**
- **`res/` 3.97 MB** hiç küçülmedi. Dil filtresi `resources.arsc`'yi
  etkiliyor, `res/` altındaki ikili kaynakları (drawable, font) etkilemiyor.
  İncelenmedi.
- **`expo.useLegacyPackaging=false` korundu.** `true` yapmak native
  kütüphaneleri APK içinde sıkıştırır ve APK'yı ~15 MB küçültür, ama kurulum
  boyutunu büyütür ve açılışı yavaşlatır. Play/AAB yolunda hiçbir faydası
  yok (Play kendi sıkıştırmasını yapar) — gerçek dağıtım AAB olduğu için
  dokunulmadı.
- **`assets/com/tom_roush/{pdfbox,fontbox}` ~0.6 MB** (CJK cmap tabloları).
  PDF rapor zincirinden geliyor; Türkçe/İngilizce raporda CJK cmap'ine ihtiyaç
  yok ama hangi cmap'in çalışma zamanında istendiğini doğrulamadan silmek
  PDF üretimini bozabilir. Bırakıldı.
- **`libreactnative.so` 5.61 MB + `libhermes.so` 2.04 MB** React Native'in
  kendisi; küçültülemez.
