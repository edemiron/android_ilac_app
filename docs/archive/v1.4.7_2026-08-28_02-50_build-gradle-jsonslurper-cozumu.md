## 🛠️ 2. Mimari Kararlar & Teknik Detaylar

1. **Eksik `import` Tanımı Eklendi:**
   - Groovy / Gradle ayrıştırıcısının sınıfı doğrudan çözümleyebilmesi için dosyanın en üstüne `import groovy.json.JsonSlurper` eklendi.
2. **Güvenli JSON Ayrıştırma & Geri Çekilme (Fallback) Mekanizması:**
   - `@react-native-firebase/app` paket dosyasının varlığı (`firebasePackageJsonFile.exists()`) kontrol edildi.
   - Dosya bulunamadığında veya dinamik okuma başarısız olduğunda sistemin çökmesini önlemek için varsayılan `"33.7.0"` Firebase BoM sürümü yedek olarak tanımlandı.

```groovy
import groovy.json.JsonSlurper

apply plugin: "com.android.application"
apply plugin: "org.jetbrains.kotlin.android"
apply plugin: "com.facebook.react"

def projectRoot = rootDir.getAbsoluteFile().getParentFile().getAbsolutePath()
def firebasePackageJsonFile = file("${projectRoot}/node_modules/@react-native-firebase/app/package.json")
def firebaseBomVersion = "33.7.0"
if (firebasePackageJsonFile.exists()) {
    def reactNativeFirebasePackageJson = new JsonSlurper().parse(firebasePackageJsonFile)
    firebaseBomVersion = reactNativeFirebasePackageJson?.sdkVersions?.android?.firebase ?: "33.7.0"
}
```
