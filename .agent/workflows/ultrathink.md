# /ultrathink - Deep Analysis Mode

$ARGUMENTS

---

## Purpose

This command activates ULTRATHINK mode - suspending brevity rules for exhaustive, multi-dimensional analysis.

---

## Behavior

When `/ultrathink` is triggered:

1. **Suspend brevity rules** - Deep explanation allowed
2. **Multi-dimensional analysis**:
   - **Psychological**: User emotions, cognitive load, UX friction
   - **Technical**: Render performance, repaint/reflow cost, state complexity
   - **Accessibility**: WCAG AAA strictness, keyboard flow, ARIA
   - **Scalability**: Modularity, long-term maintenance, team growth

3. **No superficiality** - If something looks easy, dig deeper
4. **Justify all decisions** - Every choice has rationale

```

## Key Principles

- **Depth over speed** - Take time for thorough analysis
- **Multi-angle view** - Consider all dimensions
- **Evidence-based** - Support claims with reasoning
- **Production focus** - End with actionable implementation
