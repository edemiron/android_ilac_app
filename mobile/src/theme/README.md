# 🎨 İlaç Hatırlatıcı — Tema & UI/UX Tasarım Dosyaları

Bu klasör uygulamanın UI/UX tasarım referanslarını SVG formatında içerir.

## Ekranlar
1. `home-screen.svg` — Ana Sayfa (günlük hatırlatmalar, ilerleme, zaman çizelgesi)
2. `medicines-screen.svg` — İlaçlarım (aktif/pasif ilaç listesi)
3. `statistics-screen.svg` — İstatistikler (uyum grafiği, dağılım, geçmiş)
4. `settings-screen.svg` — Ayarlar (tercihler, bildirim, hesap)
5. `add-medicine-screen.svg` — Yeni İlaç Ekle (form kartları)

## Renk Paleti
- Primary: `#0D9488` (Teal)
- Primary Dark: `#0F766E`
- Primary Light: `#14B8A6`
- Background: `#F8FAFC`
- Card: `#FFFFFF`
- Text: `#0F172A`
- Text Secondary: `#475569`
- Success: `#059669`
- Warning: `#D97706`
- Error: `#DC2626`

- Alt başlık: 16px, weight 600
